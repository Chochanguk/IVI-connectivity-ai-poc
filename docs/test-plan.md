# Test plan

| ID | 테스트 | 기대 결과 | 판정 방식 |
| --- | --- | --- | --- |
| TC-01 | Connection | Android Auto 화면 표시 | 수동 관찰 |
| TC-02 | Display Mode | Day/Night 전환 | 수동 관찰 |
| TC-03 | Audio Focus | 포커스 복구 후 재생 | 수동 관찰 |
| TC-04 | Video Focus | 화면 복귀 | 수동 관찰 |
| TC-05 | Driving Restriction | 제한 UI 동작 변경 | 수동 관찰 |
| TC-06 | Reconnection | 재연결 후 화면 복구 | 수동 관찰 |

모든 새 세션은 `NOT_RUN`입니다. 수행 후 실제 결과를 입력하고 PASS/FAIL/BLOCKED로 판정합니다. 장치 연결 해제는 사용자가 직접 수행합니다. DHU 명령은 설치된 버전의 공식 도움말에서 지원 여부를 확인하고 사용합니다.
