# 검증 기록

개발 환경: Windows 11, Python 3.12.4, Node.js 22.19.0, npm 10.9.3.

ADB `devices`: 실제 장치 1대가 `device` 상태로 조회됨. 장치 식별자는 공개하지 않음.

2026-11-07 실기기 smoke 검증: ADB API가 모델 `SM-S911N`, Android 16을 조회함. TC-01 세션을 `NOT_RUN`으로 생성하고 2초간 Logcat 수집 후 정상 중지. 마스킹된 이벤트 287건 파싱. 규칙 기반 진단 실행 결과 경고/오류 근거 ID 8개를 참조함. 이는 TC-01 수행 또는 Android Auto 장애를 뜻하지 않음.

백엔드 pytest 3개 통과, 프론트엔드 Vite 빌드 통과.

2026-11-07 17:39 KST: 사용자가 통과로 기록한 TC-02 세션에 대해 OpenAI `gpt-6-luna` 진단 1회 실행 성공. 구조화된 응답과 로그 근거 ID 검증 후 대시보드에 `OpenAI` 출처로 저장됨. 분석은 주야간 화면 변경 기록을 인정하면서, 제공된 경고·오류 로그와 화면 전환 장애의 인과관계는 확인되지 않는다고 표시함. 실제 화면 관찰은 사용자의 주간·야간 DHU 캡처가 근거이며, AI가 화면을 직접 판독한 결과는 아님.

로컬 HTTP 검증: FastAPI `/api/health` 정상, `/api/device` connected, 테스트 케이스 6개, Vue 개발 서버 `/` 200 및 `/api/sessions` 프록시 정상.

Android Auto DHU 화면 출력과 프로토콜/SSL 연결 성공은 사용자가 앞서 관찰한 결과이며, 본 PoC의 자동 검증 결과와 구분합니다.

대시보드의 판정은 각 세션의 수행·관찰 결과를 기준으로 입력합니다. 미실행 세션은 통과 건수에 포함하지 않습니다.

2026-11-07 TC-06 사용자 수행 관찰: USB 분리 후 DHU 콘솔에서 transport disconnect 및 Ping timeout 발생. 재연결 직후 DHU 실행은 실패했고 ADB 포트 포워딩 목록이 비어 있었음. `tcp:5277` 포워딩 복구 뒤 DHU를 다시 실행했을 때 `connected`, 프로토콜 1.7, SSL 협상 성공, `Verify returned: ok`를 확인함. 사용자는 연결 복구를 보고함. 이 기록은 수동 포트 포워딩 및 DHU 재실행을 포함한 복구이며, 자동 재연결 성공을 뜻하지 않음.

2026-11-07 18:02 KST TC-03 오디오 포커스 실기기 검증: 새 세션에서 Logcat 수집을 시작하고 공식 DHU 명령 `focus audio off`, `focus audio on`을 순서대로 실행함. 사용자가 음악이 멈췄다가 다시 재생되는 것을 직접 들었다고 보고해 TC-03을 `PASS`로 저장함. DHU 연결 및 SSL 협상 성공, 전후 화면 캡처 생성, Logcat 수집 종료를 확인함. 화면 캡처는 오디오 자체의 증거가 아니며, Logcat의 `AudioFocus LOSS`(L11718)와 `AudioFocus Granted`(L29508)도 명령별 인과관계까지 입증하지는 않음. 스크립트 종료 시 DHU가 비정상 종료 코드 `-1073741819`를 반환해 이를 세션 메모에 남기고 DHU를 일반 실행으로 복구함. 이 종료 현상은 별도 재현·분석 대상이며 TC-03의 청취 판정과 구분함. 캡처와 원본 로그는 `results/`에만 로컬 보관하며 Git에 포함하지 않음.

2026-11-07 로그 통계 확장 검증: TC-03 세션의 파싱 가능한 Logcat 48,220줄을 집계해 경고 5,803건, 오류·치명 1,819건, 연결·전송 분류 125건, 오디오 포커스 분류 160건, 화면·비디오 분류 135건을 대시보드에서 확인함. 분류 기준을 좁히기 전에는 일반 `Transport` 문자열까지 연결 이벤트로 잡혔으므로 이를 수정함. 이 수치는 로그 빈도와 키워드 분류 결과이며 TC-03의 장애 건수나 인과관계를 뜻하지 않음. 백엔드 pytest 4개 통과, Vue 빌드 통과. 새 AI 입력 선택 로직은 Mock 및 로그 샘플로 확인했으며 실제 OpenAI 재호출은 하지 않음.
